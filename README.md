My physics background naturally led me toward computational methods.

### 🔬 Scientific Computing

I work with numerical methods for mathematical and physical problems, including:

**Python · NumPy · SciPy · SymPy · Numba · JAX · Julia · Fortran**

### ⚡ High-Performance Computing

I've experimented with building and managing a small multi-node HPC environment using **Intel Xeon processors and ECC memory**.

My current interests include:

## 🛠️ Things I've Built

### 🏥 Diagnostic Center Management System

A production-oriented, self-hosted management platform for diagnostic centers.

**Built with:**

`Next.js` `TypeScript` `Prisma` `PostgreSQL` `Docker`

Features include:

* Patient and invoice management
* Diagnostic test management
* Doctor commissions and discounts
* Payment and due tracking
* Sales and financial reporting
* Audit logging
* Role-based administration
* Printable invoices and reports

The project has also involved **database migrations, deployment, reverse proxies, Windows packaging, backups, and self-hosted infrastructure**—making it as much a systems project as a web application.

---

### 🖥️ Experimental HPC Cluster

A small personal cluster built to experiment with parallel scientific workloads.

**Exploring:**

`MPI` `Slurm` `Linux` `Python` `Fortran` `Julia` `Numba`

The goal is to understand not just how to write numerical programs, but how computation behaves when workloads are distributed across CPUs and machines.
